# heldout.jsonl: held-out PII evaluation set

**What it is.** 200 synthetic Indian clinical notes: 120 English, 50 Hindi (Devanagari), 30 Hinglish/code-switched. There are 12 document types: discharge summary, OPD prescription, referral, ASHA home visit, lab report header, ANC card, TB/Ni-kshay follow-up, immunisation record, death and birth notification drafts, eSanjeevani-style teleconsult, and PM-JAY pre-auth. Each line is `{id, lang, doc_type, text, entities[{start, end, type, text}]}`. Offsets are Python string indices, and the generator checks `text[start:end] == entity text` for every span.

**How it was made.** `python3 make_heldout.py` (stdlib only, seed **20261115**) generates the notes from hand-written templates, name pools for many regions and religions, and real place names. Its output is byte-for-byte deterministic. The data is **fully synthetic**: no real person's data is used anywhere. The template author never saw the detector code (`gopniya/`, `scripts/`, `redactgate/`) or the dev set, so scores on this set measure generalisation.

**Labelling guideline.**
- **PERSON**: names of patients, relatives, doctors, nurses and ASHA/ANM workers. The span covers the name only; honorifics (Mr., Smt., Dr., Shri, श्री, श्रीमती, डॉ., Late, स्व., Mst., Km.) stay outside it. Later first-name or surname-only mentions are labelled too, as are bare names such as "accompanied by son Iqbal". "Mohd./Md./मो." count as part of the name. In "Baby of X", only X is labelled.
- **ADDRESS**: a person's home address, from house or village up to district/state. A PIN inside the address is part of the span. **PINCODE** is used only when the PIN stands on its own (for example a separate "PIN:" line).
- **AADHAAR**: 12 digits, first digit 2-9, valid Verhoeff check digit. Formats vary: spaced, plain, dashed, masked (`XXXX XXXX 1234`), and Devanagari digits.
- **ABHA_NUMBER**: 14 digits. **ABHA_ADDRESS**: `…@abdm` or `…@sbx`. **PAN**: 4th letter P. **VOTER_ID**: EPIC, 3 letters + 7 digits. **PHONE**: mobiles in 8 formats plus landlines with STD codes.
- **MRN**: the value of a hospital or programme record ID, with the label left out. This covers UHID, IPD/OPD, CR, MRD, lab sample ID, Ni-kshay ID, TB No., RCH/U-WIN ID, PM-JAY beneficiary ID, pre-auth number and teleconsult ID. 12-digit MRNs (CR, RCH) are generated to fail Verhoeff so they cannot pass as Aadhaar.
- **DOB**: dates of birth only, including a newborn's date of birth on birth notifications and immunisation cards.

**Deliberately unlabelled (hard negatives).** Ages, sex, admission, discharge, review and death dates, drugs and doses, lab values, bed and ward numbers, batch, lot, invoice, bill and token numbers, hospital IDs, package codes and diagnoses. Also left unlabelled: eponyms (Koch's, Bell's palsy, Austin Moore, Pritchard, Ryle's, Foley's), facility names and their locations, and admin areas such as "Sub-centre/Block". Facility names that contain person names are unlabelled on purpose: Ram Manohar Lohia Hospital, Pt. B.D. Sharma PGIMS, Dr. Bhimrao Ambedkar Memorial Hospital, and Hindi ones such as डॉ. राम मनोहर लोहिया संस्थान. Person-like words inside an address (Nihal Singh Wala, Kot Ise Khan, St. Mary's Church) belong to the ADDRESS span and are not PERSON.
